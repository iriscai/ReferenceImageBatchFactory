# 1027_六宫格参考图+画风+文案框优化完整版本

基于已确认的10月23日强参考源码，整合六宫格分镜编排、对白与旁白分离、每格文字覆盖和参考图旁白框自适应。版本备注见 `VERSION`，源码校验值见 `SOURCE_MANIFEST.json`。

## 运行

在带Tkinter的Windows Python环境中执行：

```powershell
python -m pip install -r requirements.txt
python launch_gui.py
```

也可双击 `launch_gui.cmd`。账号、标题、参考图和API配置在本地设置；仓库不包含业务数据库、密钥、参考图片或生成作品。

## 六宫格生成

- 六宫格参考图模式保留1023版原强参考规则和参考图上传流程。文本模型负责故事、分镜和文字归属，不覆盖参考图的画风。
- 参考图已有旁白样式时，继承轮廓、笔触、底色、字体和排布；没有时，按该图画风设计无尾旁白框。取消统一短矩形及固定左上角要求。
- 六宫格画风模式使用账号绑定模板，采用此前已验证的v4画风流程；此次参考图旁白自适应规则不进入画风模式。
- 每格至少有对白或旁白；无台词格按已有动作或表情补简短旁白。数字、约数、角色归属和格数校验失败时，先修正脚本，仍失败就停止生图。
- 支持语义编排、本地原文分格，以及从表格单独导出Prompt。正常作品目录不额外保存Prompt和分镜调试文件，完整记录保留在作品数据中；独立Prompt导出入口按用户选定目录保存。
- 切图使用16px白条中心识别，识别不可靠时报错并保留整图。

本版本以普通参考图/画风和两种六宫格流程为范围，保留1023历史基线的其他模式；不包含后加的形象生图分支。旧基线说明见 `docs/README.1023-original.md`，本次规则和验证范围见 `docs/release-1027-caption.md`。

## 验证

```powershell
python -m unittest discover -s tools -p test_caption_release.py -v
```

测试不调用模型或写业务数据库。包含冻结v4画风Prompt契约、参考图自适应旁白规则、文字覆盖、数字与人物归属检查。

## 打包

`PicFactoryGUI.spec`沿用历史Tk构建配置；在其他机器上请将其中的 `TK_PYTHON` 设置为本机Tk运行库目录。打包输入应使用初始化后的空白SQLite数据库，不要把个人业务数据库作为分发输入。

```powershell
python -m PyInstaller --noconfirm --clean PicFactoryGUI.spec
```

源码版本和模型输出质量应分别验收。同一输入的画风编排请求与Prompt已验证不受本次参考图规则更新影响；图像模型仍可能产生文字或绘画偏差。
