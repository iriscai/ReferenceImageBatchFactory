# 参考图分组、标签和检索（2026-11-03）

筛选对象是正在勾选的参考图片。背景与画风图、人物形象图两栏独立提供“参考图分组/分类”“参考图标签”和“名称/ID/说明”检索，支持组合筛选、未分组、未标记、一键重置。已有参考图的category直接作为分组读取；不会读取账号分组或账号标签。

参考图库原先没有独立标签数据，因此在“参考图管理 → 参考图详情”增加可选标签字段，以逗号分隔多个标签，保存后可用于选图筛选。既有图片不会被自动打标签或重分类。此字段仅是筛选元数据，不参与生图Prompt或图片上传。

筛选不改变已勾选列表和顺序，其他分组中勾选的图片仍会完整保存和上传。原有单击复选框、确定后写入草稿、取消不改配置继续保留。此前因理解错误新增的账号分组/标签筛选已撤回。

8项新测试覆盖真实图片元数据来源、组合筛选、两个选图入口、跨分组勾选保存、取消无副作用和标签保存后生图绑定一致；结合原46项回归共54项。生成、上传、多参考图Prompt、强参考画风、切图与漫流实时接收模块均保持原样。
