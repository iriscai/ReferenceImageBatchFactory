# 多参考图独立模式（2026-11-02）

新增“多参考图生图”，独立保存 `multi_reference_config`，按用途多选背景与画风图、人物形象图。“账号管理 → 公众号 → 多参考图配置”提供独立选择入口。保存此配置只更新当前账号。

每张分镜实际向图片编辑接口上传完整的原始参考图，背景在前、人物在后；不会把参考图合并成拼贴，也不会因接口错误丢弃部分参考图或改为纯文字生图。图片编辑、分镜、角色一致性和 Prompt 均由 `multi_reference_mode.py` 单独执行。正文保持原文顺序，画面内完整携带本张文字；输出编号图片和文章.txt。

背景与画风图控制整体线条、配色、背景处理、文字容器和布局；形象图控制人物身份、五官、发型、服装、体态。角色设定图的多视角、白底和排版不带入成品。默认尺寸跟随第一张背景图，可单独设置当前账号尺寸，不修改全局尺寸。

原有五种模式的图片上传函数和参考图、画风、六宫格、文字容器及切图模块不变。共同入口仅增加显式新模式分支，旧分支函数体可还原为固定版本。旧模式不读取多图配置，也不读取历史形象参考图名单；多图模式不读取普通模式的单张参考图和画风绑定。

验证包含真实 HTTP 请求参数的离线截获、每张分镜参考图原始字节及顺序、失败重试不丢图、取消请求、旧模式请求、文章模板兼容、Tk 多选筛选与取消保存、其他账号设置不被写入。所有外部模型调用均替换为测试响应，本次未额外生图，成品视觉效果仍需实际运行确认。
