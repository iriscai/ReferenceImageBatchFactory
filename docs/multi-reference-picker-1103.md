# 多参考图勾选修复（2026-11-03）

多参考图模式在普通账号编辑中仍显示单选“参考图”，而独立配置页依赖Ctrl/Shift组合键。现在，只有选择“多参考图生图”时，该字段显示“已选N张”和“勾选多张参考图”按钮。背景与画风图、人物形象图均逐张点击方框勾选，不依赖组合键；搜索不丢失勾选，显示数量及已选名称，保持勾选顺序。选择窗口确认只更新编辑草稿，账号保存时才持久化；取消编辑不改原配置。

原有五种模式保留原单选/画风控件及字段。只有账号通用列表的模态编辑增加新模式条件分支；新选择界面放在独立multi_reference_picker.py中。既有绑定解析、Prompt、生成函数、多图上传、强参考、画风、切图和漫流接收均不改。无需账号配置迁移。

测试使用真实Tk点击事件（无Ctrl）验证两张与三张勾选、数据库保存后用于生图的完整绑定、搜索、取消、普通编辑入口和旧模式单选字段。原有40项回归继续执行；本轮不调用生图接口。
