# 1027 六宫格与文案框发布说明

本版本以10月23日15:43源码为基线，保留原强参考提示词与上传函数，整合以下功能：完整对白分格、分镜执行单、文本模型语义编排、数字和人物校验、表格Prompt导出、两种六宫格模式的每格文字要求，以及16px白条切图。

本轮新增的旁白自适应仅用于参考图模式，包括语义编排和本地分格。参考图已有旁白时继承其样式与排布；没有旁白时沿用参考图媒介、线条、色彩和字体设计无尾容器，位置随本格构图安排。旁白不指向人物，对白仍指向所属人物。

画风模块、画风执行入口、共享校验与版式与已测试的v4一致。用实际产生的两份画风脚本分别在v4/v5中渲染，文本编排请求和完整图片Prompt逐字一致，并与实际图片HTTP请求核对一致。新增参考图旁白规则没有进入画风请求。

发布前完成4个真实账号的代码实跑（2个参考图、2个画风），四份作品生成成功。此前另有10账号原样批量测试，10张原图生成，其中一张由程序报告白条切图失败并保留整图；未按图像效果人工筛选或重跑。本次发布不再次调用模型。

代码、请求和图片效果的结论分开记录：模式隔离证明请求规则未改变，不能保证随机图像输出完全相同。遇到无法识别的白条时程序保留整图并报告错误。
