# 标题状态编辑与 Excel 导入（2026-11-03）

问题：标题成功生成后，used/used_at 和成功作品记录会在保存时重新把标题设为停用。编辑为启用或 Excel 明确导入启用后，同步立即改回停用，因此界面看起来没有刷新。原有导入本身已经原地替换列表并刷新，并非缺少刷新调用。

修复：标题编辑保存启用，或 Excel 状态列明确填写“启用”且确认导入后，清除该标题的旧消费标记，并记录此次重启用前的成功作品标识。旧成功作品不会再覆盖此操作，重启后仍可生成；之后的新成功仍会自动消费并停用。历史作品不删除。使用 UUID 与完成时间识别旧成功，即使前后作品的显示时间相同，新的 UUID 仍会再次消费。

标题消费仍按去空白、忽略大小写的标题全局去重。重启用会同步清理相同标题各行的消费元数据，防止重复行反向污染；只启用用户指定的行，不把其他停用行一起改为启用。失败重试也按本轮消费状态判断。再次成功后所有同名标题仍一致停用。

导入预览或取消时不修改状态。状态列缺失或为空时，不重置旧消费；普通配置保存、漫流重复推送不触发重启用。编辑、导入完成后现有列表、分类余量和可生成列表立即反映结果，保留原有筛选条件。

新增10项隔离回归，包含实际 Tk 编辑点击、真实 Excel 写入/导入、数据库结果、列表及余量、取消、空状态、重启、重复标题、新成功与失败重试。旧代码可复现编辑和 Excel 导入两项失败；修复后结合原60项共70项。生图Prompt、参考图模式、画风模式、多参考图模块、图片上传、账号配置和实时接收桥均未改动。
